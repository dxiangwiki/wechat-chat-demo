## 项目简介
本项目使用 Vue3 搭建高仿电脑端微信聊天页面，采用标准全屏布局：**宽度100%、高度100vh**，无多余横向滚动条，界面整洁贴合原生微信视觉效果，属于前端界面实战练习项目。

## 功能亮点
1. 全屏铺满浏览器窗口，布局稳定不溢出
2. 区分自己/好友双向聊天气泡样式
3. 实时输入发送聊天消息，自动获取当前时间
4. 内置可视化消息管理面板，支持新增、删除自定义聊天记录
5. 双功能开关：控制面板显示、切换静态/自定义消息数据源
6. 左侧好友列表 + 顶部标题栏 + 底部快捷工具栏完整还原
7. 聊天区域自动滚动至最新消息

## 布局规范
- 整体容器：`width:100%` `height:100vh` 标准全屏
- 左侧侧边栏固定宽度，右侧聊天区域自适应铺满剩余空间
- 全局禁止无效滚动，仅聊天内容区域支持纵向滑动

## 技术栈
- 核心框架：Vue3 Composition API
- 样式：原生 CSS
- 无第三方UI库，纯手写页面结构与样式

## 运行方式
1. 克隆项目
```bash
git clone https://github.com/dxiangwiki/wechat-chat-demo.git
```
2. 进入项目目录
```bash
cd wechat-chat-demo
```
3. 安装依赖
```bash
npm install
```
4. 启动本地运行
```bash
npm run dev
```

## 项目说明
纯前端静态交互页面，暂无后端接口对接，所有聊天数据均为前端本地存储，仅用于页面布局、Vue基础语法、移动端/桌面端全屏布局学习使用。
